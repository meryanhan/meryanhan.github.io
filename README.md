# Ryan Han

I'm a software engineer who enjoys building things from scratch, shipping them, and occasionally going down rabbit holes trying to make them faster and simpler. I mostly work with TypeScript and Rust, and tend to build and ship things on my own.

Currently, I'm building [Nisuform](https://nisuform.com/), a backend for contact forms. Point your form at it, and it takes care of spam filtering, storing submissions, and forwarding messages straight to your inbox. No server to set up, no backend code to maintain. It works with plain HTML, WordPress, React, Webflow, Wix, and pretty much anything that can submit a form.

I'm always interested in what other indie developers are working on. Show me what you're building, or just say hi. I'm usually happy to talk shop.

I'm also currently open to work. If you have something you think I'd be a good fit for, feel free to reach out.
